# Niveles

Aquí irán los scripts Bash que preparan cada reto. Todavía no están implementados.

| Archivo previsto | Reto |
|---|---|
| `nivel1_archivos_ocultos.sh` | Crear la pista oculta en una ubicación al azar |
| `nivel2_permisos.sh` | Crear `puerta.txt` sin permisos y su regla exacta de `sudo` |
| `nivel3_procesos.sh` | Iniciar el servicio `puerta_bloqueada` |
| `nivel4_usuarios.sh` | Preparar el usuario `guardia` y el grupo `boveda` |
| `nivel5_logs.sh` | Generar el log con la llave en una línea al azar |
| `nivel6_cron.sh` | Preparar la fuga final |

Cada script debe ejecutar antes `../scripts/comprobar_entorno.sh` y detenerse si falla.
